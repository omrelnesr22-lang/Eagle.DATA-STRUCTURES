01 · البداية

ما هي هياكل البيانات؟

أشكال يتم بها تمثيل البيانات التي تحتاج إلى تخزينها واسترجاعها بأسهل وأسرع خطوات ممكنة.

لماذا نحتاج هياكل بيانات متعددة؟

  • يوجد العديد من هياكل البيانات، ويتم الاختيار بينها حسب المشكلة وطريقة التخزين والاسترجاع المناسبة.
  • تُستخدم هياكل البيانات في تطبيقات الموبايل والكمبيوتر والألعاب (Games)، حيث يستخدم كل منها هيكل أو أكثر بطرق تناسبه.
  • من أشهر الهياكل المتعارف عليها: Array ، Stack ، Tree.

أمثلة استخدام

تطبيقات الموبايل، تطبيقات الكمبيوتر، الألعاب — كل منها يستخدم هيكل أو أكثر بطريقة تناسبه.

02 · المقياس

الكفاءة (Efficiency)

ترتبط الكفاءة بحسن استغلال الموارد المتاحة، من أهمها الوقت والمجهود والأموال. كلما استطعنا أن نوفر من هذه الموارد، كلما أصبحنا أكثر كفاءة.

لماذا نقارن هياكل البيانات؟

لكي نختار هيكل البيانات المناسب لكل مشكلة، علينا مقارنة هياكل البيانات المختلفة لكي نصل إلى الهيكل الذي سيساعدنا في حل المشكلة بشكل أسرع.

طالما يوجد هيكل بيانات أفضل من هيكل آخر، فبالتأكيد يوجد معيار يجعلنا نستطيع معرفة كفاءة كل هيكل.

موارد الكمبيوتر

أهم مورَدين لدى الكمبيوتر هما الوقت والمساحة (السعة التخزينية).

عند تشغيل برنامج معين أكثر من مرة، سنجد قراءات مختلفة للوقت والمساحة — وذلك لأن نظام التشغيل يكون مشغّلًا أكثر من عملية في نفس الوقت، فيقوم بعمل تبديل السياق (Context Switching): ميزة لنظام التشغيل متعدد المهام تسمح بمشاركة وحدة المعالجة المركزية الواحدة عبر عمليات متعددة.

Garbage Collection: يعمل على تحرير مساحة الذاكرة المخصصة للكائنات التي لم يعد البرنامج بحاجة إليها.

03 · القياس الرياضي

دالة النمو والتدوينات المقاربة

دالة النمو (Growth Function) تحاول إيجاد علاقة بين عدد العمليات التي تحتاج أن تُنفَّذ وبين قيمة المدخلات أو عددها.

مثال: حلقة واحدة

public static void printHello(int n) { for(int i = 0; i < n; i++) { System.out.format("Hello! \n"); } }

الحلقة تُنفَّذ عدد n من المرات، فكلما زاد n زاد عدد العمليات وقلّت الكفاءة. نعبّر عنها بمعادلة خطية: Y = n

مثال: حلقة متداخلة

for(int i = 0; i < n; i++) { for(int j = 0; j < n; j++) { System.out.format("Hello! i=%d,j=%d\n", i, j); } }

السطر الداخلي يُنفَّذ n*n أي n² مرة — أقل كفاءة من المثال السابق: Y = n²

جدول مقارنة نمو القيم

nnn²n³

10010010,0001,000,000

تبسيط المعادلات — التدوينات المقاربة (Asymptotic Notation)

تُستخدم لوصف وقت تشغيل الخوارزمية، أي مقدار الوقت الذي تستغرقه مع إدخال معين. عند تعويض قيمة كبيرة لـ n، الحدّ الأكبر هو ما يهيمن على الناتج، وباقي المعادلة يُهمَل.

Y = 2n² + n + 4 // المعادلة الأصلية Y = 3n² // إهمال الحدود الأصغر Y = n² // حذف المعامل الثابت 3 // → معادلة النمو النهائية: O(n²)
Big O → Worst case Omega → Best case Theta → Average case

04 · هيكل ثابت الحجم

المصفوفة — Array

هيكل بيانات يقوم بتخزين مجموعة عناصر بشكل معيّن وترتيب معيّن. يجب أن تكون جميع العناصر من نفس النوع، ونحدّد مساحتها التخزينية مسبقًا.

طرق التعريف والتهيئة

int[] numbers; int []numbers; int numbers[]; // تهيئة بمساحة محددة int[] numbers = new int[10]; // تهيئة بقيم مباشرة int[] numbers = {5,4,10,9,2};

تصنيف العمليات على Array

استرجاع / تغيير قيمة عنصرO(1)
النسخ (Copy)O(n)
البحث عن عنصر (Linear Search)O(n)
إضافة/حذف في البداية أو المنتصفأسوأ العمليات

إذا واجهت عملية من الصنف الأخير كثيرًا، فكّر في هيكل بيانات آخر بدلًا من Array.

النسخة السطحية Shallow Copy

عملية النسخ في Array تنسخ العناوين (Addresses) فقط عند وجود Objects، وليس الكائنات نفسها.

النسخة العميقة Deep Copy

تنسخ الكائنات فعليًا، وتكون غالبًا عملية يدوية يقوم بها المبرمج.

المصفوفات متعددة الأبعاد

// ثنائية الأبعاد — مساحة ثابتة للأعمدة int[][] arr = new int[10][5]; // ثنائية الأبعاد — بقيم مبدئية int[][] arr = {{1,2,5,0},{4},{8,3}}; // ثلاثية الأبعاد int[][][] numbers = new int[4][ ][ ]; // استرجاع كل العناصر: Nested for loop for (int i = 0; i < arr.length; i++) { for(int j = 0; j < arr[i].length; j++) { System.out.println(arr[i][j]); } }

يجب تحديد عدد الصفوف عند التعريف؛ أما عدد الأعمدة فاختياري تحديده مسبقًا.

05 · هيكل مرن

المصفوفة الديناميكية — ArrayList

ArrayList = خصائص Array + مرونة List. يأخذ من Array طريقة التخزين، ويأخذ من List أنك لست مقيّدًا بتحديد عدد العناصر مسبقًا.

التعريف — ولاحظ: العناصر يجب أن تكون Objects

import java.util.ArrayList; ArrayList<Integer> myList = new ArrayList<>(); ArrayList<Integer> myList = new ArrayList<>(10); ArrayList<Integer> myList = new ArrayList<>( Arrays.asList(new Integer(2), new Integer(5), new Integer(8)));

عملية الإضافة والحذف بالتفصيل

arrList.add(new Integer(10)); // إضافة في النهاية arrList.add(2, new Integer(10)); // إضافة عند index محدد arrList.remove(2); // حذف عنصر index رقم 2 arrList.remove(object); // حذف أول تكرار لهذا العنصر فقط

كيف تنمو مساحة ArrayList داخليًا؟

عند تعريف ArrayList فارغ، يُحجز بداخله Array بحجم افتراضي (Default Size) يبلغ تقريبًا 10. عندما لا تكفي المساحة لعنصر جديد، يُحجز Array جديد مساحته = 1.5 × المساحة القديمة، ثم تُنقل جميع العناصر القديمة إليه بنفس الترتيب.

ArrayList يُخزّن Array بداخله، لكنه لا يُظهر لك مساحة هذا الـ Array ولا كيف تزداد.

06 · LIFO

الرصة — Stack

السلوك المميّز للـ Stack هو Last In First Out (LIFO): آخر شيء يدخل هو أول شيء يخرج. للوصول إلى عنصر، يجب أن نكون قد مررنا بالعناصر السابقة له (Sequential access) — بعكس Array الذي يسمح بالوصول العشوائي (Random access).

السلوك (LIFO)

2
5
8
20 ←

آخر عنصر أُضيف هو أول عنصر يُسترجع.

التعريف

Stack<Integer> myStack = new Stack<>();

لا يتم تحديد عدد العناصر مسبقًا، ونوع العناصر يجب أن يكون Object.

العمليات الأساسية

push() — إضافة عنصر لأعلى الرصةO(1)
pop() — استرجاع وحذف آخر عنصرO(1)
peek() — معرفة قيمة آخر عنصر دون حذفهO(1)
size() — عدد العناصرO(1)
isEmpty() — هل الرصة فارغة؟O(1)
search() — تحديد مكان عنصر—

عند استخدام pop() يجب استخدام الناتج بسرعة، وإلا فلن تجده إن خرجت من الـ Scope.

أمثلة تقنية على استخدام Stack

  • Call Stack: موقع في الذاكرة يُخزَّن فيه استدعاء الدوال. لكل دالة "إطار" (Frame) يحتوي أسماء المتغيرات وقيمها وموقعها، ليعرف المعالج أين يعود بعد الانتهاء من تنفيذ الدالة المستدعاة.
  • لغات الترميز (HTML/XML): يجب قفل أي وسم بنفس ترتيب فتحه العكسي — تمامًا كسلوك الرصة.

التخزين والوراثة

الرصة (Stack) ترث (Inherit) من Class يُسمى Vector، وتُخزَّن عناصرها كمصفوفة (Array) — بنفس طريقة تخزين ArrayList.

07 · FIFO

الطابور — Queue & Deque

بنية بيانات خطية مفتوحة من كلا الطرفين، تُنفَّذ عملياتها بترتيب First In First Out (FIFO): الذي يدخل أولًا يخرج أولًا — كأي طابور نراه في حياتنا.

السلوك (FIFO)

Enqueue →
5
9
3
8
2
→ Dequeue

Queue مقابل Stack

الطابور عكس الرصة تمامًا: سلوك Queue هو FIFO، بينما سلوك Stack هو LIFO. عند إضافة عنصر في Queue، يُضاف دائمًا في النهاية — وليس في البداية أو المنتصف.

Java ليس بها Class اسمه Queue، بل واجهة (Interface) تسمى Queue — لا يمكن إنشاء كائن منها مباشرة، فقط من فئة تنفّذها.

Deque — الطابور ثنائي الاتجاه

Deque اختصار Double-Ended Queue: واجهة تُوسّع Queue، وتسمح بالإدخال والإخراج من أي اتجاه. يمكنها محاكاة سلوك Queue، أو عكسه، أو حتى محاكاة سلوك Stack.

فحصgetFirst()peekFirst()getLast()peekLast()

ArrayDeque — التنفيذ الفعلي والتعقيد

لا ينفّذ ArrayDeque واجهة Queue مباشرة، بل ينفّذ Deque، وهي بدورها تنفّذ Queue. يُخزَّن كمصفوفة (Array)، وعند الامتلاء تُنشأ مصفوفة جديدة بمساحة أكبر — تمامًا كآلية ArrayList.

لحلّ مشكلة حذف أول عنصر (والتي تكلّف O(n) في مصفوفة عادية بسبب إزاحة العناصر)، يستخدم ArrayDeque فكرة Circular Array: سهمان أحدهما يشير لبداية الدخول والآخر لبداية الخروج، فلا حاجة لإزاحة العناصر.

إدخال عنصر (Enqueue)O(1)
إخراج عنصر (Dequeue) — عبر Circular ArrayO(1) Amortized
النظر لأول عنصرO(1)

متى نستخدم Queue؟

عندما تحتاج تخزين بيانات كثيرة بالترتيب، لتسترجعها لاحقًا بنفس هذا الترتيب.

  • طلب أكل من مطعم: الطلبات تُجهَّز بنفس ترتيب دخولها إلى الطابور.
  • تشغيل نظام التشغيل لأكثر من برنامج: يضع كل برنامج في طابور، ثم يشغّل الأول فالذي يليه بسرعة كبيرة حتى لا تشعر بالتبديل.
08 · خلفية برمجية

Class و Interface

مفهومان أساسيان يفسّران كيف تُبنى هياكل البيانات في Java من الداخل.

ما هي الفئة (Class)؟

تمثّل مجموعة الخصائص أو الطرق المشتركة بين جميع الكائنات من نوع واحد.

مثال: مصنع سيارات — جميع السيارات تشترك في وجود محرك ودواسات ومقاعد، لكن الطراز واللون قد يختلفان من سيارة لأخرى.

ما هي الواجهة (Interface)؟

عقد يحتوي على شروط وبنود على هيئة دوال (Functions)، ويجب على أي فئة تنفّذه (Implement) أن توفّر هذه الدوال بنفس الاسم والمدخلات والمخرجات.

مثال: مفتاح واحد قد يفتح باب المنزل أو السيارة أو الخزنة — لأن لها جميعًا نفس "واجهة" فتحة القفل، رغم أنها كائنات مختلفة تمامًا لا علاقة بينها.

Iterable & Iterator

لكي تتمكن فئة ما من العمل مع for each loop، يجب أن تنفّذ واجهتي Iterable و Iterator.

for(Integer item : myList) { System.out.println(item); } myList.forEach(item -> System.out.println(item));
